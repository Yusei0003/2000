# 日直勤務表 自動作成アプリ

「日直勤務表の作成及び変更等についてのマニュアル」および追加仕様確認書に基づき、毎年4〜9月・10〜翌3月に行っている日直勤務表（土日祝日・年末年始の当番表）の作成を自動化する、ブラウザだけで動くツールです。サーバー不要、データはブラウザのlocalStorageに保存されます。

## できること

- **処理期（年度前期・後期）ごとの管理**：画面上部で処理期（例：2026年度 前期＝4〜9月／後期＝10〜翌3月）を選び、その処理期に対する作業として進めます。処理期を切り替えると、名簿の設定・ルール・勤務表作成の対象期間・履歴タブの表示がその処理期の内容に切り替わります
  - 新しい処理期を作成すると、直前の処理期の「市民課経験者」「常時除外する所属」を自動的に引き継ぎます（「前回処理期からコピー」ボタンでいつでも引き継ぎ直せます）。退職等で名簿にいない職員・所属は自動的に除かれます。過去の年度も自由に作成できます
  - 「この処理期を削除」で処理期そのものを削除できます。紐づく確定済み履歴は削除されず「未分類」として残り、ペア重複回避・間隔日数の判定には引き続き使用されます（履歴・確認タブの表示フィルタで「未分類」を選ぶと確認できます）
  - 終了日が過去の処理期を選択すると案内が表示され、名簿登録・ルール設定・勤務表作成を省き、履歴・確認タブの「Excel勤務実績データの取り込み」だけで過去の日直割を登録する運用ができます
- **職員名簿の管理**：職員番号・氏名・級（係長級／主事級）・性別・職名・所属課・係名・兼職・採用年月日・市民課経験の有無を登録（CSV取込／書出、および人事給与システム等から出力したExcel名簿の直接取込に対応）。性別はExcel取込時にのみ自動設定され、手入力での指定はできません。一覧は所属CD順に表示され、番号・氏名・所属・係名・職名で検索できます。表示は<strong>対象者リスト</strong>（日直の割当対象）と<strong>除外リスト</strong>（秘書係・運転手・派遣・7割措置・常時除外所属・対象外（手動設定）のいずれかに該当する職員）の2つに分かれます
- **Excelデータの取込**：
  - 名簿：番号・氏名・職名・所属CD・所属名・性別・係名・兼職・区分名・ランク・採用日等の列を含む.xlsxをそのまま取込可能。級は<strong>ランク</strong>から自動判定します（1〜399：課長級以上は除外／400〜600：係長級／601〜999：主事級／1000以降：会計年度任用職員等は除外）。ランクが読み取れない行のみ、職名ごとに「係長級／主事級／取り込まない」を指定します（次回以降の取込にも記憶されます）。性別は<strong>1＝男性、0＝女性</strong>として自動判定します。区分名が「会計年度任用職員」「派遣」の職員、退職者・非在職者も自動的に取込対象から除外されます。出力方法：人事給与システムで「在職・写真無・詳細」の条件で検索し、Ctrl+Aで全選択して任意のExcelに貼り付ける
  - 勤務実績：過去の日直勤務表（.xlsx）を取り込むと、選択中の処理期に紐づけて履歴として自動登録されます。名簿にない職員番号は履歴専用の職員として自動追加され、担当状況の確認に利用できます
- **ルール設定**：
  - 最低間隔日数（既定120日）、新規採用職員の除外期間（既定6ヶ月）、年末年始・GWの遡り回数（既定2回）、ペア重複の遡り年度数（既定2年度）
  - 資格要件：毎日の組合せのうち少なくとも1名が係長級または市民課経験者である必要があります（設定不要）
  - 常時除外する所属（外局等）を、名簿に登録済みの所属からチェックボックスで選択（所属CD順に表示）。秘書係は係名から、運転手は兼職欄から自動的に常時除外されます
  - 外部組織へ派遣中の職員（区分名が正職員のまま人事データに残るため自動判定できない）は、名簿の「派遣（除外）」列にチェックを入れることで常時除外できます。60歳以上で7割措置（再任用短時間等）の職員も同様に「7割措置（除外）」列で常時除外できます。名簿は番号・氏名・所属等で検索でき、該当職員を素早く見つけられます
  - 育休・産休等による除外期間：人事システム等から出力した育休一覧（職員番号・氏名・区分・開始・終了の列を含む .xlsx／出力方法：「休業情報」で該当年1/1以降の「終了」を検索）、産休一覧（職員番号・氏名・出産予定日・出産日・産前休暇・産後休暇・備考の列を含む .xlsx／出力方法：「出産情報」で該当年1/1以降の「産前休暇」を検索。除外期間は産前休暇〜産後休暇）をそのまま取り込めます。個別に職員番号・開始日・終了日で登録することもできます（終了日が未定の場合は空欄のまま登録でき、復帰まで対象外として扱われます）。同じ職員・同じ期間の行は取込時に自動でスキップされ、名簿にない職員番号（会計年度任用職員等）の行は取込対象外になります
  - 月別の課除外ルール（10・11月の商工観光課・広報係、12・1月のふるさと納税係、1〜4月の税務課など）
- **行事管理（年度別）**：年度ごとに行事（産業まつり・花火大会・選挙・成人式等）の日程・除外リードタイム（既定30日前から）・除外する所属を登録。前年度の行事をコピーして日付だけ入力し直せます
- **勤務表の自動作成**：対象期間を指定すると土日・祝日・年末年始（12/28〜1/3）を自動抽出し、以下のルールを踏まえて係長級1名・主事級1名を自動で割り当てます
  - 日直のペアは<strong>同性</strong>で組みます。<strong>女性を優先して割り当て、その日に条件を満たす女性の候補（係長級・主事級のいずれか）が枯渇している場合のみ男性</strong>に切り替えます（枯渇ベース）。性別が未設定の職員は割当対象になりません
  - 資格要件（係長級または市民課経験者が最低1名）を満たす
  - 同じ課同士は組み合わせない
  - 過去2年度（設定可）以内に組んだペアは避ける
  - 前回勤務日から120日（設定可）以上間隔を空ける
  - 年末年始・ゴールデンウィークは過去の同期間（既定で直近2回）と同じ職員を避ける
  - 育休・産休等の登録期間中の職員、月別・行事別（リードタイム含む）の課除外ルールを反映
  - すべてを満たす組合せがない場合は制約を段階的に緩和し、それでも決められない日は「要確認」として表示します
  - 作成結果の一覧の下に、今回の作成分で一度も割り当てられなかった対象職員と、その理由（育休・産休中、前回勤務日から120日未満、所属除外ルールに該当、新規採用除外期間中、女性を優先するルールでその日は対象にならなかった、他の職員が優先された、など）を表示します（確定前に偏りや原因を確認できます）
- **履歴管理**：確定した勤務表は履歴として自動的に蓄積され、次回作成時の間隔日数計算・年末年始重複回避・ペア重複回避に自動反映されます
- **変更届の反映**：確定済みの勤務表に対して、変更届による交代を反映できます（交代後の氏名と申請日時を入力）。変更申請のスクリーンショット画像から氏名・日時を自動で読み取り、入力欄に下書きすることもできます（読み取り結果は確認・修正のうえ反映します。手入力もそのまま利用可）。反映した変更日時はPDF・引継ぎ用Excel出力にそのまま表示されます
- **出力**：CSV・PDF（画面表示をそのまま画像化してPDF化）・引継ぎ用Excel（担当交代の際、履歴を丸ごと次の担当者へ渡せます）
- **確認機能**：職員ごとの担当回数・直近勤務日を一覧表示し、担当履歴のない職員がいないか確認できます（マニュアルの「名簿との#N/A確認」に相当）。「履歴を見る」で職員ごとに過去の全勤務日を確認できます
- **データのバックアップ**：名簿・ルール設定・行事・確定済み履歴・育休期間など、全データを1つのJSONファイルにまとめて書き出し・復元できます。機種変更やブラウザのデータ消去に備えて、定期的な作成を推奨します

## 使い方

1. `index.html` をブラウザで開く（ダブルクリックでOK。もしくは `python3 -m http.server` 等で配信）
2. 画面上部で**処理期**を選ぶ（初めての期は「処理期を追加」で作成。直前の処理期の設定を引き継ぎます。過去の年度も作成できます）
3. **名簿管理**タブで、まず「1. Excel名簿データの取り込み」を実行（部課長級・外局・秘書・運転手・会計年度任用職員・派遣は自動的に除外されます）。続けて「2. 職員名簿」で市民課経験・派遣（除外）・7割措置（除外）等を確認します
4. **ルール設定**タブで各種ルールを確認・調整（常時除外する所属、育休・産休等の除外期間など）
5. **行事管理**タブで年度ごとの行事日程・除外所属を登録
6. **勤務表作成**タブで「土日・祝日・年末年始を自動抽出」→「勤務表を作成する」（対象期間は処理期から自動入力されます）
7. 内容を確認し、必要なら手動で調整した上で「確定・履歴に保存」
8. **履歴・確認**タブで確定済み内容の確認、変更届の反映、CSV・PDF・引継ぎ用Excel出力、全データのバックアップができます（表示は選択中の処理期が既定です。「全期間」「未分類」にも切り替えられます）

過去分の日直割だけを登録したい場合（名簿登録や勤務表作成が不要な場合）は、対象年度の処理期を作成し、**履歴・確認**タブの「Excel勤務実績データの取り込み」だけで登録できます。

### 新しい処理期で勤務表を作る（名簿等は登録済みの場合）

1. 処理期セレクタで「処理期を追加」から新しい年度・区分（前期／後期）を作成する（直前の処理期の「市民課経験者」「常時除外する所属」を自動引継ぎ）
2. 育休・産休で新たに対象になった職員がいれば**ルール設定**タブで登録・取込する
3. **行事管理**タブでその年度の行事日程を登録する（「前年度の行事をコピー」や「前年度の登録状況（参考）」を活用）
4. **勤務表作成**タブで「土日・祝日・年末年始を自動抽出」→「勤務表を作成する」（対象期間は処理期から自動入力済み）
5. 内容を確認し「確定・履歴に保存」

## 注意事項

- データはブラウザ（端末）ごとのlocalStorageに保存されます。他の端末とは共有されません。共用端末では使用しないでください。データ消去や機種変更に備え、**履歴・確認**タブの「バックアップを作成する」で定期的にJSONファイルへ保存しておくことをおすすめします。
- 祝日は計算式（ハッピーマンデー・振替休日・国民の休日を含む）による自動判定です。念のため作成後の一覧で確認してください。
- 自動割当はあくまで補助です。「要確認」表示の日や、組織の実情に応じた微調整は手動で行ってください。
- PDF出力は画面表示を画像化する方式のため、PDF内の文字はコピーできません。
- 変更届のスクリーンショット読み取り（OCR）機能は、`index.html` を`python3 -m http.server`等で配信して開いている場合のみ使用できます。ダブルクリックで直接開いた場合（`file://`）はブラウザの制約により使用できません。この場合も手入力での交代反映は引き続き使用できます。
- OCRの読み取り結果は誤読することがあります（特に人名の漢字）。必ず内容を確認し、必要に応じて手入力で修正してから「反映する」を押してください。
- Excel取込・PDF出力・OCR機能は以下のライブラリを同梱して実現しており、外部通信は行いません（`vendor/`配下）。
  - [SheetJS](https://sheetjs.com/)（`xlsx.core.min.js`、Apache License 2.0）
  - [html2canvas](https://html2canvas.hertzen.com/)（`html2canvas.min.js`、MIT License）
  - [jsPDF](https://github.com/parallax/jsPDF)（`jspdf.umd.min.js`、MIT License）
  - [Tesseract.js](https://github.com/naptha/tesseract.js) / [tesseract.js-core](https://github.com/naptha/tesseract.js-core)（`tesseract*.js`、Apache License 2.0）＋ 日本語学習データ（`jpn.traineddata.gz`、[tessdata_fast](https://github.com/tesseract-ocr/tessdata_fast)、Apache License 2.0）

## 担当交代時の手順

1. 前任者：**履歴・確認**タブの「引継ぎ用に書き出す」でExcelファイルを出力し、後任者へ受け渡す
2. 後任者：自身の端末でExcel名簿を取り込み、続けて引継ぎファイルをExcel勤務実績の取込機能で読み込む
3. 前任者：引継ぎ完了後、ブラウザの閲覧データ削除によりlocalStorageの内容を消去する
