# 日直勤務表 自動作成アプリ

「日直勤務表の作成及び変更等についてのマニュアル」および追加仕様確認書に基づき、毎年4〜9月・10〜翌3月に行っている日直勤務表（土日祝日・年末年始の当番表）の作成を自動化する、ブラウザだけで動くツールです。サーバー不要、データはブラウザのlocalStorageに保存されます。

## できること

- **職員名簿の管理**：職員番号・氏名・級（係長級／主事級）・職名・所属課・係名・兼職・採用年月日・市民課経験の有無を登録（CSV取込／書出、および人事給与システム等から出力したExcel名簿の直接取込に対応）
- **Excelデータの取込**：
  - 名簿：番号・氏名・職名・所属名・係名・兼職・区分名・採用日等の列を含む.xlsxをそのまま取込可能。職名ごとに「係長級／主事級／取り込まない」を指定でき、次回以降の取込にも記憶されます（部課長級など対象外の職名は自動で「取り込まない」を提案）。区分名が「会計年度任用職員」「派遣」の職員、退職者・非在職者は自動的に取込対象から除外されます
  - 勤務実績：過去の日直勤務表（.xlsx）を取り込むと、履歴として自動登録されます。名簿にない職員番号は履歴専用の職員として自動追加され、担当状況の確認に利用できます
- **ルール設定**：
  - 最低間隔日数（既定120日）、新規採用職員の除外期間（既定6ヶ月）、年末年始・GWの遡り回数（既定2回）、ペア重複の遡り年度数（既定2年度）
  - 資格要件の対象役職（既定：補佐・副主幹・係長・主任・主任主事・主任技師）を追加・削除可能。毎日の組合せのうち少なくとも1名がこの役職または市民課経験者である必要があります
  - 常時除外する所属（外局等）を自由入力で登録。秘書係は係名から、運転手は兼職欄から自動的に常時除外されます
  - 月別の課除外ルール（10・11月の商工観光課・広報係、12・1月のふるさと納税係、1〜4月の税務課など）
- **行事管理（年度別）**：年度ごとに行事（産業まつり・花火大会等）の日程・除外リードタイム（既定30日前から）・除外する所属を登録。前年度の行事をコピーして日付だけ入力し直せます
- **勤務表の自動作成**：対象期間を指定すると土日・祝日・年末年始（12/28〜1/3）を自動抽出し、以下のルールを踏まえて係長級1名・主事級1名を自動で割り当てます
  - 資格要件（対象役職または市民課経験者が最低1名）を満たす
  - 同じ課同士は組み合わせない
  - 過去2年度（設定可）以内に組んだペアは避ける
  - 前回勤務日から120日（設定可）以上間隔を空ける
  - 年末年始・ゴールデンウィークは過去の同期間（既定で直近2回）と同じ職員を避ける
  - 月別・行事別（リードタイム含む）の課除外ルールを反映
  - すべてを満たす組合せがない場合は制約を段階的に緩和し、それでも決められない日は「要確認」として表示します
- **履歴管理**：確定した勤務表は履歴として自動的に蓄積され、次回作成時の間隔日数計算・年末年始重複回避・ペア重複回避に自動反映されます
- **変更届の反映**：確定済みの勤務表に対して、変更届による交代を反映できます（交代後の氏名と申請日時を入力）。反映した変更日時はPDF・引継ぎ用Excel出力にそのまま表示されます
- **出力**：CSV・PDF（画面表示をそのまま画像化してPDF化）・引継ぎ用Excel（担当交代の際、履歴を丸ごと次の担当者へ渡せます）
- **確認機能**：職員ごとの担当回数・直近勤務日を一覧表示し、担当履歴のない職員がいないか確認できます（マニュアルの「名簿との#N/A確認」に相当）。「履歴を見る」で職員ごとに過去の全勤務日を確認できます

## 使い方

1. `index.html` をブラウザで開く（ダブルクリックでOK。もしくは `python3 -m http.server` 等で配信）
2. **名簿管理**タブで対象職員を登録（部課長級・外局・秘書・運転手・会計年度任用職員・派遣は、Excel取込であれば自動的に除外されます）
3. **ルール設定**タブで各種ルールを確認・調整
4. **行事管理**タブで年度ごとの行事日程・除外所属を登録
5. **勤務表作成**タブで対象期間を入力し「土日・祝日・年末年始を自動抽出」→「勤務表を作成する」
6. 内容を確認し、必要なら手動で調整した上で「確定・履歴に保存」
7. **履歴・確認**タブで確定済み内容の確認、変更届の反映、CSV・PDF・引継ぎ用Excel出力ができます

## 注意事項

- データはブラウザ（端末）ごとのlocalStorageに保存されます。他の端末とは共有されません。共用端末では使用しないでください。
- 祝日は計算式（ハッピーマンデー・振替休日・国民の休日を含む）による自動判定です。念のため作成後の一覧で確認してください。
- 自動割当はあくまで補助です。「要確認」表示の日や、組織の実情に応じた微調整は手動で行ってください。
- PDF出力は画面表示を画像化する方式のため、PDF内の文字はコピーできません。
- Excel取込・PDF出力機能は以下のライブラリを同梱して実現しており、外部通信は行いません（`vendor/`配下）。
  - [SheetJS](https://sheetjs.com/)（`xlsx.core.min.js`、Apache License 2.0）
  - [html2canvas](https://html2canvas.hertzen.com/)（`html2canvas.min.js`、MIT License）
  - [jsPDF](https://github.com/parallax/jsPDF)（`jspdf.umd.min.js`、MIT License）

## 担当交代時の手順

1. 前任者：**履歴・確認**タブの「引継ぎ用に書き出す」でExcelファイルを出力し、後任者へ受け渡す
2. 後任者：自身の端末でExcel名簿を取り込み、続けて引継ぎファイルをExcel勤務実績の取込機能で読み込む
3. 前任者：引継ぎ完了後、ブラウザの閲覧データ削除によりlocalStorageの内容を消去する
