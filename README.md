# 日直勤務表 自動作成アプリ

「日直勤務表の作成及び変更等についてのマニュアル」および追加仕様確認書に基づき、毎年4〜9月・10〜翌3月に行っている日直勤務表（土日祝日・年末年始の当番表）の作成を自動化する、ブラウザだけで動くツールです。サーバー不要、データはブラウザのlocalStorageに保存されます。

## できること

- **処理期（年度前期・後期）ごとの管理**：画面上部で処理期（例：2026年度 前期＝4〜9月／後期＝10〜翌3月）を選び、その処理期に対する作業として進めます。処理期を切り替えると、名簿・ルール・勤務表作成の対象期間・履歴タブの表示がその処理期の内容に切り替わります
  - <strong>名簿は処理期ごとに管理します。</strong>新しい処理期を作成したら、その期のExcel名簿を取り込んでください（人事異動を反映した最新の名簿を処理期ごとに取り込む運用です）。新しい処理期を作成すると、直前の処理期の「常時除外する所属」を自動的に引き継ぎます（「前回処理期からコピー」ボタンでいつでも引き継ぎ直せます）
  - 「この処理期を削除」で処理期そのものを削除できます。紐づく確定済み履歴は削除されず「未分類」として残り、ペア重複回避・間隔日数の判定には引き続き使用されます（履歴・確認タブの表示フィルタで「未分類」を選ぶと確認できます）
  - 終了日が過去の処理期を選択すると案内が表示され、名簿登録・ルール設定・勤務表作成を省き、履歴・確認タブの「Excel勤務実績データの取り込み」だけで過去の日直割を登録する運用ができます
- **職員名簿の管理**：職員番号・氏名・級（係長級／主事級）・性別・職名・所属課・係名・兼職・身分・年齢・採用年月日・退職予定日・市民課経験の有無・選挙管理委員会事務局の併任の有無を登録（CSV取込／書出、および人事給与システム等から出力したExcel名簿の直接取込に対応）。性別はExcel取込時にのみ自動設定され、手入力での指定はできません。退職予定日は名簿一覧で直接編集でき、退職予定日の1ヶ月前（設定可）を過ぎた職員は日直の割当対象から自動的に外れます。一覧は所属CD順に表示され、番号・氏名・所属・係名・職名で検索できます。表示は<strong>対象者リスト</strong>（日直の割当対象）と<strong>除外リスト</strong>（秘書係・運転手・派遣・7割措置・常時除外所属・対象外（手動設定）のいずれかに該当する職員）の2つに分かれます。同一人物は職員番号によって処理期をまたいで同一の職員として扱われるため、名簿を処理期ごとに取り込み直しても、120日間隔・ペア重複回避などの履歴に基づく判定は継続して機能します。<strong>まだ名簿を取り込んでいない処理期では、名簿の一覧は表示されず、取込を促す案内のみが表示されます。</strong>「この処理期の名簿を削除」でその処理期の名簿を消し、未取込の状態に戻せます。「Excel取込で除外された人をCSV書出」「除外リストの人をCSV書出」で、それぞれ除外された職員を職員番号・区分名・身分・名前・所属名・職名・年齢（除外リストは除外理由も）の列でCSV出力できます
- **Excelデータの取込**：
  - 名簿：番号・氏名・職名・所属CD・所属名・性別・係名・兼職・区分名・身分・年度年齢・ランク・採用日・退職日等の列を含む.xlsxをそのまま取込可能。級は<strong>ランク</strong>から自動判定します（1〜399：課長級以上は除外／400〜600：係長級／601〜999：主事級／1000以降：会計年度任用職員等は除外）。ランクが読み取れない行のみ、職名ごとに「係長級／主事級／取り込まない」を指定します（次回以降の取込にも記憶されます）。性別は<strong>1＝男性、0＝女性</strong>として自動判定します。区分名が「会計年度任用職員」「派遣」の職員も自動的に取込対象から除外されます。<strong>退職日</strong>は退職予定日として名簿に取り込まれ、選択中の処理期の開始日より前の日付が入っている場合（＝既に退職済み）のみ取込対象から除外されます。身分・年度年齢はそのまま名簿の「身分」「年齢」に表示されます。出力方法：人事給与システムで「在職・写真無・詳細」の条件で検索し、Ctrl+Aで全選択して任意のExcelに貼り付ける
    - <strong>取り込むと、選択中の処理期の名簿は今回の内容にすべて置き換わります</strong>（この処理期で個別に追加した職員も置き換え対象）。前回処理期に登録されていた同じ職員番号の「市民課経験」「派遣（除外）」「7割措置（除外）」は自動的に引き継がれます。現在の所属が市民課の職員は「市民課経験」が自動的にチェックされます
  - 勤務実績：過去の日直勤務表（.xlsx）を取り込むと、選択中の処理期に紐づけて履歴として自動登録されます。名簿にない職員番号は、どの処理期の名簿にも属さない履歴専用の職員として自動追加され、担当状況の確認に利用できます
- **ルール設定**：
  - 最低間隔日数（既定120日）、新規採用職員の除外期間（既定6ヶ月）、年末年始・GWの遡り回数（既定2回）、ペア重複の遡り年度数（既定2年度）、退職予定日の何ヶ月前まで割当対象とするか（既定1ヶ月）
  - 資格要件：毎日の組合せのうち少なくとも1名が係長級または市民課経験者である必要があります（設定不要）
  - 常時除外する所属（外局等）を、名簿に登録済みの所属からチェックボックスで選択（所属CD順に表示）。秘書係は係名から、運転手は兼職欄から自動的に常時除外されます
  - 外部組織へ派遣中の職員（区分名が正職員のまま人事データに残るため自動判定できない）は、名簿の「派遣（除外）」列にチェックを入れることで常時除外できます。60歳以上で7割措置（再任用短時間等）の職員も同様に「7割措置（除外）」列で常時除外できます。名簿は番号・氏名・所属等で検索でき、該当職員を素早く見つけられます
  - 育休・産休・病気休暇等による除外期間：人事システム等から出力した育休一覧（職員番号・氏名・区分・開始・終了の列を含む .xlsx／出力方法：「休業情報」で該当年1/1以降の「終了」を検索）、産休一覧（職員番号・氏名・出産予定日・出産日・産前休暇・産後休暇・備考の列を含む .xlsx／出力方法：「出産情報」で該当年1/1以降の「産前休暇」を検索。除外期間は産前休暇〜産後休暇）をそのまま取り込めます。<strong>病気休暇や個人的な事情で日直ができない職員も含め</strong>、個別に職員番号・区分（任意の自由記述）・開始日・終了日で登録することもできます（終了日が未定の場合は空欄のまま登録でき、復帰まで対象外として扱われます）。同じ職員・同じ期間の行は取込時に自動でスキップされ、名簿にない職員番号（会計年度任用職員等）の行は取込対象外になります
  - 月別の課除外ルール（10・11月の商工観光課・広報係、12・1月のふるさと納税係、1〜4月の税務課など）
- **行事管理（年度別）**：年度ごとに行事（産業まつり・花火大会・選挙・成人式等）の日程・除外リードタイム（既定30日前から）・除外を続ける日数（行事日の何日後まで、既定10日）・除外する所属を登録。前年度の行事をコピーして日付だけ入力し直せます。選挙は「選挙管理委員会事務局を併任している職員も対象にする」を選ぶと、選挙管理委員会事務局という所属が名簿上に無くても、名簿で「選挙管理委員会（併任）」にチェックした職員を告示日の前後（除外リードタイム〜除外を続ける日数）の期間だけ対象から外せます
- **勤務表の自動作成**：対象期間を指定すると土日・祝日・年末年始（12/29〜1/3）を自動抽出し、以下のルールを踏まえて2名（1人目は係長級、2人目は係長級・主事級のどちらでもよい）を自動で割り当てます
  - <strong>1日2名のうち少なくとも1名が係長級であればよい</strong>ため、係長級1名＋主事級1名（基本形）に加えて、<strong>係長級2名の組合せ</strong>にもなります。両方とも同等の組合せとして扱われます。係長級2名を組む場合、双方の職名が「課長補佐」「副主幹」のいずれかに該当する組合せ（課長補佐＋課長補佐／課長補佐＋副主幹／副主幹＋副主幹）は避けます
  - 日直のペアは<strong>同性</strong>で組みます。<strong>女性を優先して割り当て、女性ゾーンから男性ゾーンへ一方向に切り替わります</strong>（女性優先・性別ゾーン方式）。その日に割り当てられる未割当の女性が1人もいなくなった日から男性ゾーンに切り替わり、<strong>いったん男性ゾーンに入ったら、その処理期の残りは女性を一切割り当てません</strong>（男性の期間の途中に女性が単発で混ざると担当交代がしづらくなるため）。性別が未設定の職員は割当対象になりません。<strong>性別ごとの日数の枠は設けません</strong>——各性別に割り当てられる日数は、女性ゾーン・男性ゾーンそれぞれの長さに応じて、その処理期の男女の人数から自然に決まります
  - <strong>同一処理期内は原則1人1回の割当</strong>とします。探索は「女性の未割当 → 男性の未割当 → 女性の2回目 → 男性の2回目」の順に行い、<strong>男女いずれの未割当も尽きた場合に限り</strong>2回目の割当を許可して「要確認」として表示します（女性の2回目より男性の1回目が先に使われるため、男性が一度も割り当てられないまま女性が2回目に回ることはありません）
  - 資格要件（係長級または市民課経験者が最低1名）を満たす（1人目が必ず係長級のため、実質的には常に満たされます）
  - 同じ課同士は組み合わせない
  - 過去2年度（設定可）以内に組んだペアは避ける
  - 前回勤務日から120日（設定可）以上間隔を空ける
  - 年末年始・ゴールデンウィークは過去の同期間（既定で直近2回）と同じ職員を避ける
  - 育休・産休等の登録期間中の職員、月別・行事別（リードタイム含む）の課除外ルールを反映
  - すべてを満たす組合せがない場合は制約を段階的に緩和し、それでも決められない日は「要確認」として表示します
  - <strong>人数不足を可能な限り防ぐ</strong>ため、その時点のゾーンの性別だけではどうしてもペアが組めない日は、係長級の有無を問わない最終手段で対象者を自動で最大限（2名、無理なら1名）割り当てます（<strong>性別はゾーンに固定したまま</strong>で、他方の性別で埋めることはしません）。それでも対象者が残らない場合は、最後に120日ルールも外して探します（在籍者がいるのに誰も当番に立てない日を作らないため。その場合は理由に「前回勤務日から120日未満の職員を含みます」と表示します）。2名の枠を埋められなかった日（1名のみ、または対象者が1人もいない日）は「状態」欄に赤色で<strong>「エラー：（理由）」</strong>として表示します
  - 作成結果の一覧の下に、今期まだ一度も割り当てられていない対象職員と、その理由（育休・産休中、前回勤務日から120日未満、所属除外ルールに該当、新規採用除外期間中、女性を優先するルールでその日は対象にならなかった、今期の割当枠が他の職員で埋まったため、など）を表示します（確定前に偏りや原因を確認できます）
  - 結果一覧の各欄には職員名の札が表示され、<strong>ドラッグして別の日・別の欄（1人目・2人目をまたいでも可）の職員と入れ替え</strong>られます。プルダウンでの変更もそのまま使えます。入れ替え・変更後は、係長級が含まれているか・性別が一致しているか・同一課でないか・課長補佐や副主幹の組合せでないか・同一処理期内で2回目の割当になっていないかを自動で再判定し、問題があれば「要確認」として理由を表示します
- **確定前の決裁確認**：勤務表作成タブに「勤務表の内容を確認・決裁してから確定してください。」の注意書きを常時表示し、「決裁が完了したことを確認しました」にチェックを入れないと確定できません。指定日の対象変更・作り直し・プルダウン変更・ドラッグ入れ替えを行うとチェックは自動的に外れ、確定前に改めて確認が必要になります
- **確定後の状態保持と引き戻し**：確定すると、指定日・結果一覧・未割当職員や担当過多のサマリはそのまま画面に残り、処理期の切替やページの再読み込みを行っても消えません（確定時点の内容としてそのまま保持されます）。確定中は自動抽出・作成・プルダウン変更・ドラッグ入れ替えができないようロックされ、自動処理等で内容が変わることはありません。修正が必要な場合は「引き戻して修正」でロックを解除できます（この回の確定分は確定済み履歴から削除されますが、引き戻し前の内容は「作成履歴」として保持され、件数の確認とCSVでの再出力ができます）。修正後は再度決裁確認のうえ確定できます
- **履歴管理**：確定した勤務表は履歴として自動的に蓄積され、次回作成時の間隔日数計算・年末年始重複回避・ペア重複回避に自動反映されます。個別の日を削除する以外に、履歴・確認タブの「表示中の履歴を一括削除」で、表示フィルタ（全期間／未分類／各処理期）に絞り込まれている確定済み履歴をまとめて削除することもできます（削除前に件数を確認します）
- **変更届の反映**：確定済みの勤務表に対して、変更届による交代を反映できます（交代後の氏名と申請日時を入力）。グループウェア等の申請内容画面をコピーしてテキストエリアに貼り付けると、交代相手氏名・申請日時・変更する日付・申請者を自動で読み取り、入力欄に下書きします（貼り付けるだけで自動実行、ボタンでも再実行可）。変更申請のスクリーンショット画像からの読み取りにも対応しています。どちらも読み取った変更対象日が該当行と異なる場合や、読み取った申請者が現在の担当者と異なる場合は警告を表示します（読み取り結果は確認・修正のうえ反映します。手入力もそのまま利用可）。反映した変更日時はPDF・引継ぎ用Excel出力にそのまま表示されます
- **出力**：CSV・PDF（画面表示をそのまま画像化してPDF化）・引継ぎ用Excel（担当交代の際、履歴を丸ごと次の担当者へ渡せます）。勤務表PDFの列見出しはいずれも「氏名」で統一しています（係長級・主事級の別は見出しに出しません）。また処理期の前半3ヶ月・後半3ヶ月を指定ページに分けて出力します（前期：1ページ目＝4〜6月／2ページ目＝7〜9月。後期：1ページ目＝10〜12月／2ページ目＝1〜3月）
- **確認機能**：担当実績のある職員の担当回数・直近勤務日を一覧表示します（表示は選択中の処理期の履歴が既定で、「履歴を見る」で職員ごとに過去の全勤務日を確認できます）。一度も割り当てられていない職員の確認（マニュアルの「名簿との#N/A確認」に相当）は、<strong>勤務表作成</strong>タブの「2. 勤務表を作成」で理由付きで確認できます。同じ画面に、今期の担当回数が2回以上の職員（最大・平均の担当回数付き）も一覧表示され、担当回数の偏りを確認できます
- **データのバックアップ**：名簿・ルール設定・行事・確定済み履歴・育休期間など、全データを1つのJSONファイルにまとめて書き出し・復元できます。機種変更やブラウザのデータ消去に備えて、定期的な作成を推奨します

## 使い方

1. `index.html` をブラウザで開く（ダブルクリックでOK。もしくは `python3 -m http.server` 等で配信）
2. 画面上部で**処理期**を選ぶ（初めての期は「処理期を追加」で作成。直前の処理期の「常時除外する所属」を引き継ぎます。過去の年度も作成できます）
3. **名簿管理**タブで、まず「1. Excel名簿データの取り込み」を実行（部課長級・外局・秘書・運転手・会計年度任用職員・派遣は自動的に除外されます）。名簿は処理期ごとに管理されるため、この取り込みは処理期ごとに毎回行います。前回処理期に登録されていた「市民課経験」「派遣（除外）」「7割措置（除外）」は該当する職員に自動的に引き継がれます。続けて「2. 職員名簿」で内容を確認します
4. **ルール設定**タブで各種ルールを確認・調整（常時除外する所属、育休・産休等の除外期間など）
5. **行事管理**タブで年度ごとの行事日程・除外所属を登録
6. **勤務表作成**タブで「土日・祝日・年末年始を自動抽出」→「勤務表を作成する」（対象期間は処理期から自動入力されます）
7. 内容を確認し、必要なら手動で調整した上で決裁を受け、「決裁が完了したことを確認しました」にチェックを入れてから「確定・履歴に保存」（確定後も画面の内容はそのまま保持され、修正が必要な場合は「引き戻して修正」でロックを解除できます）
8. **履歴・確認**タブで確定済み内容の確認、変更届の反映、CSV・PDF・引継ぎ用Excel出力、全データのバックアップができます（表示は選択中の処理期が既定です。「全期間」「未分類」にも切り替えられます）

過去分の日直割だけを登録したい場合（名簿登録や勤務表作成が不要な場合）は、対象年度の処理期を作成し、**履歴・確認**タブの「Excel勤務実績データの取り込み」だけで登録できます。

### 新しい処理期で勤務表を作る（名簿等は登録済みの場合）

1. 処理期セレクタで「処理期を追加」から新しい年度・区分（前期／後期）を作成する（直前の処理期の「常時除外する所属」を自動引継ぎ）
2. **名簿管理**タブでこの処理期のExcel名簿を取り込む（前回処理期の「市民課経験」「派遣（除外）」「7割措置（除外）」が該当する職員に自動的に引き継がれます）
3. 育休・産休で新たに対象になった職員がいれば**ルール設定**タブで登録・取込する
4. **行事管理**タブでその年度の行事日程を登録する（「前年度の行事をコピー」や「前年度の登録状況（参考）」を活用）
5. **勤務表作成**タブで「土日・祝日・年末年始を自動抽出」→「勤務表を作成する」（対象期間は処理期から自動入力済み）
6. 内容を確認し、決裁を受けたうえで「決裁が完了したことを確認しました」にチェックを入れ、「確定・履歴に保存」

## 注意事項

- データはブラウザ（端末）ごとのlocalStorageに保存されます。他の端末とは共有されません。共用端末では使用しないでください。データ消去や機種変更に備え、**履歴・確認**タブの「バックアップを作成する」で定期的にJSONファイルへ保存しておくことをおすすめします。
- 祝日は計算式（ハッピーマンデー・振替休日・国民の休日を含む）による自動判定です。念のため作成後の一覧で確認してください。
- 自動割当はあくまで補助です。「要確認」表示の日や、組織の実情に応じた微調整は手動で行ってください。
- PDF出力は画面表示を画像化する方式のため、PDF内の文字はコピーできません。
- 変更届のスクリーンショット読み取り（OCR）機能は、`index.html` を`python3 -m http.server`等で配信して開いている場合のみ使用できます。ダブルクリックで直接開いた場合（`file://`）はブラウザの制約により使用できません。この場合も手入力、および変更届のテキスト貼り付けによる読み取りは引き続き使用できます。
- OCRの読み取り結果は誤読することがあります（特に人名の漢字）。必ず内容を確認し、必要に応じて手入力で修正してから「反映する」を押してください。
- 変更届のテキスト貼り付けは、貼り付けた文章の中から「交代相手氏名」「申請日」「変更する日付」「申請者」の各ラベルを探して読み取る方式のため、これらのラベル文言を含まない形式の文章では読み取れません（この場合も手入力は使用できます）。
- Excel取込・PDF出力・OCR機能は以下のライブラリを同梱して実現しており、外部通信は行いません（`vendor/`配下）。
  - [SheetJS](https://sheetjs.com/)（`xlsx.core.min.js`、Apache License 2.0）
  - [html2canvas](https://html2canvas.hertzen.com/)（`html2canvas.min.js`、MIT License）
  - [jsPDF](https://github.com/parallax/jsPDF)（`jspdf.umd.min.js`、MIT License）
  - [Tesseract.js](https://github.com/naptha/tesseract.js) / [tesseract.js-core](https://github.com/naptha/tesseract.js-core)（`tesseract*.js`、Apache License 2.0）＋ 日本語学習データ（`jpn.traineddata.gz`、[tessdata_fast](https://github.com/tesseract-ocr/tessdata_fast)、Apache License 2.0）
