# 日直勤務表 自動作成アプリ

「日直勤務表の作成及び変更等についてのマニュアル」に基づき、毎年3月・9月（およびその都度の変更）に行っている日直勤務表（土日祝日の当番表）の作成を自動化する、ブラウザだけで動くツールです。サーバー不要、データはブラウザのlocalStorageに保存されます。

## できること

- **職員名簿の管理**：職員番号・氏名・級（係長級／主事級）・所属課・採用年月日・市民課経験の有無を登録（CSV取込／書出対応）
- **ルール設定**：最低間隔日数（既定120日）、新規採用職員の除外期間（既定6ヶ月）、月別の課除外ルール（10・11月の商工観光課・広報係、12・1月のブランド推進係など）、行事による当日除外（全国太鼓フェスティバル等）
- **勤務表の自動作成**：対象期間を指定すると土日・祝日を自動抽出し、以下のルールを踏まえて係長級1名・主事級1名を自動で割り当てます
  - 市民課経験者と主事級の組合せを優先
  - 同じ課同士は組み合わせない
  - 前回勤務日から120日（設定可）以上間隔を空ける
  - 年末年始・ゴールデンウィークは過去の同期間（既定で直近2回）と同じ職員を避ける
  - 月別・行事別の課除外ルールを反映
  - 自動で決められない日は「要確認」として表示し、手動で選び直せます
- **履歴管理**：確定した勤務表は履歴として自動的に蓄積され、次回作成時の間隔日数計算・年末年始重複回避に自動反映されます（マニュアルにあった「過去の履歴をコピペする」作業が不要になります）
- **確認機能**：職員ごとの担当回数・直近勤務日を一覧表示し、担当履歴のない職員がいないか確認できます（マニュアルの「名簿との#N/A確認」に相当）

## 使い方

1. `index.html` をブラウザで開く（ダブルクリックでOK。もしくは `python3 -m http.server` 等で配信）
2. **名簿管理**タブで対象職員を登録（部課長級・外局・秘書はあらかじめ含めない）
3. **ルール設定**タブで各種ルールを確認・調整
4. **勤務表作成**タブで対象期間を入力し「土日・祝日を自動抽出」→「勤務表を作成する」
5. 内容を確認し、必要なら手動で調整した上で「確定・履歴に保存」
6. **履歴・確認**タブで確定済み内容やCSV出力を確認

## 注意事項

- データはブラウザ（端末）ごとのlocalStorageに保存されます。他の端末とは共有されません。
- 祝日は計算式（ハッピーマンデー・振替休日・国民の休日を含む）による自動判定です。念のため作成後の一覧で確認してください。
- 自動割当はあくまで補助です。「要確認」表示の日や、組織の実情に応じた微調整は手動で行ってください。
