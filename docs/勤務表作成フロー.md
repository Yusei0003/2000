# 勤務表作成フロー

本書は、勤務表作成タブで「勤務表を作成する」を押したときの処理の流れを、実装に即して記載したものです。ルールの内容が実際の運用と合っているかの確認にご使用ください。

| 項目 | 内容 |
| --- | --- |
| 版数 | 1.2 |
| 作成日 | 2026-08-19 |
| 対象 | 勤務表作成タブ（`generateAssignments`） |
| 関連文書 | 仕様書（`docs/仕様書.md`）、設計書（`docs/設計書.md`） |

---

## 1. 全体フロー（画面操作）

```mermaid
flowchart TD
    A[処理期を選択] --> B[対象期間が自動入力される<br/>開始日=処理期の開始日／終了日=処理期の終了日]
    B --> C[土日・祝日・年末年始を自動抽出]
    C --> D{抽出結果}
    D -->|0件| E[理由を表示<br/>・すべて確定済み履歴に含まれる<br/>・対象日がない]
    D -->|1件以上| F[指定日の一覧を表示<br/>不要な日はチェックを外す]
    F --> G[勤務表を作成する]
    G --> H[割当処理<br/>※第2章]
    H --> I[結果一覧を表示<br/>OK／要確認＋理由]
    I --> J[今期まだ割り当てられていない<br/>対象職員と理由を表示]
    J --> K{内容を確認}
    K -->|修正する| L[プルダウン選択、または職員名の札を<br/>ドラッグして入れ替え<br/>→ 変更内容を自動で再判定]
    L --> K
    K -->|問題なし| M[確定・履歴に保存]
    M --> N[処理期に紐づけて履歴に記録]
    N --> O[CSV／PDFで出力]
```

**指定日の抽出条件**

| 種別 | 条件 |
| --- | --- |
| 土曜・日曜 | 曜日による判定 |
| 祝日 | 計算式による自動判定（春分・秋分は近似式、ハッピーマンデー・振替休日・国民の休日を含む） |
| 年末年始閉庁日 | 12/29〜1/3（曜日を問わない） |
| 除外 | 既に確定済み履歴に存在する日付は抽出しない |

## 2. 割当処理のフロー

### 2.1 前処理（1回だけ実行）

確定済み履歴の全件から、判定に使う情報を集計します。

```mermaid
flowchart TD
    A[確定済み履歴の全件] --> B[担当回数<br/>職員ごとの累計担当回数]
    A --> C[前回勤務日<br/>職員ごとの最終勤務日]
    A --> D[特別期間の使用者<br/>年末年始・GWごとの担当者]
    A --> E[ペアの最終年度<br/>組合せごとの最後に組んだ年度<br/>※変更届による交代の組合せは除く]
    A --> F[今期の割当済み職員<br/>※選択中の処理期の履歴のみ]
    G[職員名簿<br/>選択中の処理期] --> H[対象職員を抽出<br/>・対象外（手動設定）を除く<br/>・常時除外を除く]
    H --> I[割当対象の職員リスト]
```

**常時除外の判定（この時点で対象から外れる）**

| No | 条件 |
| --- | --- |
| 1 | 名簿の「派遣（除外）」がオン |
| 2 | 名簿の「7割措置（除外）」がオン |
| 3 | 係名または所属名に「秘書係」を含む |
| 4 | 兼職欄に「運転手」を含む |
| 5 | 所属名が、処理期の「常時除外する所属」のいずれかを含む |
| 6 | 名簿の「対象に含める」がオフ |

### 2.2 日ごとの処理

指定日を**日付の古い順**に1日ずつ処理します。前の日の割当結果は、次の日の判定に反映されます（担当回数・前回勤務日・今期割当済みが更新されるため）。

```mermaid
flowchart TD
    A[対象日] --> B[その日の除外所属を集計]
    B --> B1[月別の課除外ルール<br/>その月に該当する所属]
    B --> B2[行事の除外<br/>除外開始日〜終了日に該当する所属]
    A --> C{年末年始・GWか}
    C -->|該当する| D[過去2回の同期間の担当者を<br/>この日の対象から外す]
    C -->|該当しない| E[制限なし]
    B1 --> F[候補プールの作成]
    B2 --> F
    D --> F
    E --> F
    F --> G[女性・今期未割当で探す<br/>※第2.4章]
    G --> H{決まったか}
    H -->|決まらない| J[男性・今期未割当で探す]
    J --> K{決まったか}
    K -->|決まらない| L[女性・今期2回目で探す]
    L --> L2{決まったか}
    L2 -->|決まらない| M[男性・今期2回目で探す]
    M --> M2{決まったか}
    M2 -->|決まらない| Q[最終手段：性別・係長級を問わず<br/>対象者を最大限割り当てる<br/>※第2.4a章]
    H -->|決まった| N[状態を判定]
    K -->|決まった| N
    L2 -->|決まった| N
    M2 -->|決まった| N
    Q --> N
    N --> O[結果を記録し、<br/>担当回数・前回勤務日・<br/>今期割当済みを更新]
    O --> P[次の日へ]
```

**性別ごとの日数の枠は設けません。** 「今期未割当」を男女とも試し切ってから「今期2回目」に進むため、各性別に割り当てられる日数は、その処理期の男女の人数に応じて自然に決まります（3.1節）。

### 2.3 候補プールの作成条件

対象職員のうち、以下を**すべて**満たす職員だけが、その日・その性別の候補になります。

| No | 条件 | 内容 |
| --- | --- | --- |
| 1 | 性別が一致 | 女性の候補／男性の候補をそれぞれ作る（性別未設定は候補にならない） |
| 2 | 育休・産休等の期間外 | 対象日が登録された除外期間に含まれない（終了日が空欄の場合は復帰まで対象外） |
| 3 | 除外所属でない | 所属名が、その日の除外所属（月別・行事別）のいずれも含まない |
| 4 | 特別期間の重複でない | 年末年始・GWの場合、過去2回（設定可）の同期間で担当していない |
| 5 | 新規採用の除外期間外 | 対象日が「採用日＋6ヶ月（設定可）」以降 |
| 6 | 最低間隔日数を満たす | 前回勤務日から120日（設定可）以上経過している |

上記を満たす候補から、**1人目プール**（係長級のみ）と、**2人目プール**（係長級・主事級を問わない全員）の2つを作ります。2人目プールに係長級も含めるのは、「1日2名のうち少なくとも1名が係長級であればよい」ため、係長級2名の組合せも成立させるためです。

### 2.4 ペアの決定（同一性別内）

```mermaid
flowchart TD
    A[1人目プール：係長級<br/>2人目プール：係長級・主事級] --> B[今期2回目を許可しない区分では<br/>今期まだ割り当てていない<br/>職員だけに絞る]
    B --> C{第1段階<br/>ペア重複回避＋職名の組合せ回避＋同一課回避}
    C -->|見つかった| C1[OK]
    C -->|なし| D{第2段階<br/>ペア重複回避を緩和}
    D -->|見つかった| D1[要確認：過去のペアと重複]
    D -->|なし| E{第3段階<br/>職名の組合せ回避も緩和}
    E -->|見つかった| E1[要確認：課長補佐・副主幹の組合せ]
    E -->|なし| F{第4段階<br/>同一課回避も緩和}
    F -->|見つかった| F1[要確認：同一課の組合せ]
    F -->|なし| G{第5段階<br/>資格要件も緩和}
    G -->|見つかった| G1[要確認：資格要件を満たさない]
    G -->|なし| H{1人目プールに<br/>1名以上いるか}
    H -->|いる| H1[1人目の先頭候補と、<br/>2人目プールの先頭候補<br/>（1人目と別人）を組む<br/>要確認]
    H -->|0名| K[この区分ではペアを組めない<br/>→ 次の区分へ（2.2章）]
```

**「職名の組合せ回避」の内容**：2人目も係長級の場合、1人目・2人目の職名が両方とも「課長補佐」「副主幹」のいずれかに該当する組合せ（課長補佐＋課長補佐／課長補佐＋副主幹／副主幹＋副主幹）を避けます。2人目が主事級の場合はこの判定自体を行いません。

**候補の並び順（先頭から評価される）**

| プール | 並び順 |
| --- | --- |
| 1人目（係長級のみ） | ①資格要件を満たす者を優先（係長級は全員該当） → ②累計担当回数が少ない順 → ③前回勤務日が古い順（担当履歴のない職員を最優先） |
| 2人目（係長級・主事級） | 級による優先は行わず、②累計担当回数が少ない順 → ③前回勤務日が古い順のみで並べる |

2人目の並び順から級による優先を外しているのは、係長級2名の組合せと係長級＋主事級の組合せを、担当回数等の実績に基づいて対等に扱うためです（同じ実績であれば、どちらの組合せになるかは先頭からの探索順に依存します）。この並び順により、ある処理期で割り当てられなかった職員は、次の処理期で優先的に選ばれます。

### 2.4a 最終手段（人数不足対応）

2.2章の4区分すべてでペアが組めなかった場合、**人数不足を可能な限り防ぐ**ため、性別・係長級の有無を問わずに対象者を最大限割り当てます。

```mermaid
flowchart TD
    A[4区分すべてで組めなかった] --> B[性別を問わない候補で探す<br/>※120日ルールは維持]
    B --> C{対象者は}
    C -->|係長級が1名以上| D[その係長級＋担当回数の少ない候補]
    C -->|係長級が0名・2名以上| E[担当回数の少ない候補2名<br/>エラー：係長級が含まれていません]
    C -->|1名のみ| F[その1名だけを割り当てる<br/>エラー：人数不足のため1名のみ]
    C -->|0名| G[120日ルールも外して再探索]
    G --> H{対象者は}
    H -->|1名以上| I[同じ判定をやり直す<br/>要確認：前回勤務日から120日未満を含む]
    H -->|0名| J[割当なし<br/>エラー：対象者がいません]
```

120日ルールを外す2周目を設けているのは、処理期の後半では全職員が「前回勤務日から120日以内」に該当しうるため、これがないと**在籍者がいるのに誰も当番に立てない日**が発生してしまうためです。

### 2.5 状態（OK／要確認／エラー）の判定

| 状態 | 条件 | 表示 |
| --- | --- | --- |
| OK | 1人目・2人目の両方が決まり、かつ第1段階で決まり、かつ今期2回目でない | — |
| 要確認 | 2名は決まったが、緩和が発生した／今期2回目になった | 黄色 |
| エラー | **2名の枠を埋められなかった**（1名のみ、または誰も割り当てられなかった） | 赤色 |

**理由（複数該当する場合は「/」区切りで併記）**

| 理由 | 発生条件 |
| --- | --- |
| 対象者がいません（休暇・除外等により、この日に割当可能な職員が1人もいません） | 最終手段（120日ルールの緩和を含む）でも対象者が0名 |
| 人数不足のため1名のみの割当です（相方となる対象者がいません） | 対象者が1名しかいない |
| 係長級が含まれていません（人数不足のため） | 最終手段で、係長級が1名もいないまま2名を組んだ |
| 性別が異なる組合せです（人数不足のため） | 最終手段で、男女混在のまま2名を組んだ |
| 前回勤務日から120日未満の職員を含みます（人数不足のため） | 最終手段の2周目で、最低間隔日数の判定を外して組んだ |
| 同一処理期内で2回目の割当です | 男女とも今期未割当の候補が枯渇し、2回目の割当を許可した |
| 資格要件（係長級・市民課経験者）を満たす職員がいません | 第5段階まで緩和した（1人目は必ず係長級のため、実質的には発生しません） |
| 同一課の組合せになっています | 第4段階まで緩和した |
| 課長補佐・副主幹の組合せになっています | 第3段階まで緩和した |
| 過去のペアと重複しています | 第2段階まで緩和した |

**手動調整（プルダウン・ドラッグ）後の再判定**：プルダウンでの変更、または結果一覧の名前の札をドラッグして入れ替えた場合、変更後の組合せを次の観点で再判定し、いずれかに該当すれば「要確認」または「エラー」として理由を表示します（入れ替え自体は常に許可します）。

| 理由 | 発生条件 | 状態 |
| --- | --- | --- |
| 対象者がいません | 1人目・2人目とも未定 | エラー |
| 人数不足のため1名のみの割当です | 1人目・2人目のどちらかが未定 | エラー |
| 係長級が含まれていません | 1人目・2人目のどちらも係長級でない | 要確認 |
| 性別が異なる組合せです | 1人目・2人目の性別が一致しない | 要確認 |
| 同一課の組合せです | 1人目・2人目が同じ所属課 | 要確認 |
| 課長補佐・副主幹の組合せです | 1人目・2人目がともに係長級で、職名が課長補佐・副主幹の組合せ | 要確認 |
| 同一処理期内で2回目の割当です | 選んだ職員が、選択中の処理期の他の日（確定済み履歴・今回の作成分の両方）で既に割り当てられている | 要確認 |

## 3. ご確認いただきたい点

実装上、ルール同士が競合する箇所があります。以下の動作が運用の意図と合っているかご確認ください。

### 3.1 「女性優先」と「1人1回」の優先順位（確定事項）

**1人1回が女性優先より優先**されます。その日に「今期まだ割り当てていない男性」がいる場合は、「今期すでに1回割り当てた女性」より先に、**男性の1回目**が選ばれます。

```
その日の状況：
  女性の係長級候補 … 今期割当済みの職員のみ
  男性の係長級候補 … 今期未割当の職員がいる

動作： 男性の1回目を割り当てる（OK）
```

探索は次の順に行い、最初にペアが得られた区分を採用します。

| 順 | 区分 |
| --- | --- |
| 1 | 女性・今期未割当 |
| 2 | 男性・今期未割当 |
| 3 | 女性・今期2回目 |
| 4 | 男性・今期2回目 |

**性別ごとの日数の枠は設けません。** 各性別に割り当てられる日数は、その処理期の男女の人数に応じて自然に決まります。女性が少ない職場では、男性が担当する日数が多くなります（例：女性6名・男性60名で63日を作成した場合、女性ペア6日・男性ペア57日）。

> 当初は「女性優先」を2回目の割当まで含めて解釈していたため、男性が一度も割り当てられていないのに女性が2回目に回る動作になっていました。女性が少ない職場では男性の日数が不自然に少なくなるため、上記のとおり修正しています。

### 3.2 「1人1回」の枯渇判定の単位

1人1回のルールは、**その日・その性別・その1人目プール／2人目プールごと**に判定します（2人目プールは係長級・主事級を合わせた1つのプールです）。

例えば、女性の2人目プールだけが今期全員割当済みで、女性の1人目（係長級）プールには未割当者がいる場合、その日の女性ペアは「1人目＝1回目・2人目＝2回目」の組合せになります（要確認）。ただし3.1のとおり、この判定に入る前に「男性・今期未割当」が試されます。

### 3.3 段階的緩和と2回目の割当の順序

現在の実装では、**未割当者だけで組める限り、制約を緩和してでも未割当者を優先**します。

```
未割当者だけで探す：第1段階 → 第2段階 → 第3段階 → 第4段階 → 第5段階 → 先頭同士
        ↓ それでも組めない場合のみ
割当済みも含めて探す：第1段階 → 第2段階 → …
```

つまり「同一課になってでも、あるいは課長補佐・副主幹の組合せになってでも未割当者を使う」動作になります。「これらを避けるほうを優先し、2回目の割当を許容する」とすべき場合は、その旨をお知らせください。

### 3.4 資格要件の実質的な影響

資格要件は「ペアのうち少なくとも1名が係長級または市民課経験者」です。1人目は必ず係長級のため、**この要件は常に満たされます**。第5段階（資格要件の緩和）に到達することは実質的にありません。

2人目の選定では、係長級2名の組合せと係長級＋主事級の組合せを対等に扱うため、**資格要件（市民課経験者かどうか）による優先は行いません**。累計担当回数・前回勤務日のみで並べ、担当回数が同じ場合は探索順（1人目に近い側から）で決まります。

### 3.5 過去の実績の扱い

担当回数・前回勤務日・ペア重複・年末年始/GWの重複は、**処理期を問わず全ての確定済み履歴**から判定します。1人1回のルールだけが、選択中の処理期の履歴に限定されます。

### 3.6 変更届による交代の扱い

変更届で交代した組合せは、**ペア重複回避の判定対象外**です。一方、担当回数・前回勤務日・年末年始/GWの重複・1人1回の判定では、交代後の職員が担当したものとして扱われます。

### 3.7 係長級2名の組合せ（確定事項）

「1日2名のうち係長級が最低1名いればよい」ため、係長級2名の組合せも許可しました。ご確認いただいた内容に基づき、以下のとおり実装しています。

- 係長級2名の組合せは、係長級＋主事級の組合せと**対等に扱います**（主事級の候補がいない日限定の代替措置ではありません）
- 係長級2名を組む場合、双方の職名が「課長補佐」「副主幹」のいずれかに該当する組合せ（課長補佐＋課長補佐／課長補佐＋副主幹／副主幹＋副主幹）は避けます（第3段階で緩和）

### 3.8 結果一覧でのドラッグ入れ替え（確定事項）

勤務表作成タブの結果一覧で、各欄の職員名の札をドラッグして、別の日・別の欄の職員と入れ替えられるようにしました。ご確認いただいた内容に基づき、**列（1人目・2人目）をまたいだ入れ替えも許可**しています。

入れ替え（およびプルダウンでの変更）は常に許可したうえで、変更後の組合せを次の観点で自動的に再判定し、違反があれば「要確認」として理由を表示します：係長級が含まれているか、性別が一致しているか、同一課でないか、課長補佐・副主幹の組合せでないか、同一処理期内で2回目の割当になっていないか。ペア重複回避（過去2年度）は手動変更時には再判定していません。

## 4. 具体例

### 4.1 通常のケース

```
対象日：2026-08-15（土）
```

### 4.2 今期の候補が枯渇したケース

```
対象日：2027-02-13（土）
```
